## 0.3.42 — Recording with a softer pulse

- The desktop start button now uses a microphone icon with a fine outer rim.
- During recording, a broad theme-colored halo expands from the button edge and gradually fades away.
- Pausing stops the animation; resume, busy and disabled states retain clear controls.
- Respects the system reduced-motion preference. Recording, saving and the floating recorder workflow remain unchanged.

## 录音按钮焕新

- 准备录音时显示麦克风图标与细外圈。
- 录音中，一层厚实的主题色色环从按钮边缘扩散，逐渐放大、变淡并消失。
- 暂停即停止扩散，继续、处理中和禁用状态均有清晰反馈。
- 支持系统“减少动画”设置；录音、保存与胶囊窗口的操作逻辑保持不变。
